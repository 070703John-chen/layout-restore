# 05 · 快速开始

---

## 1. 安装

```bash
git clone https://github.com/070703John-chen/layout-restore.git
cd layout-restore

# Python 3.9+
pip install -r requirements.txt

# 出图需要 chromium（只装一次）
python -m playwright install chromium
```

或者装成命令：

```bash
pip install -e .
layout-restore --help
```

> Windows 上注意：只有装了 chromium 的那个 Python 能出图。
> 用 `python -c "import playwright; print('ok')"` 确认。

---

## 2. 跑一遍

```bash
# 生成示例图（程序绘制，原创素材）
python examples/make_samples.py --out examples/samples

# 一条命令跑完整链
python -m layout_restore.cli build --src examples/samples/demo_param_card.png --key demo_param_card

# 从交付源件包重渲并对账
python -m layout_restore.cli verify --pack out/demo_param_card

# 状态板 / 指标表 / 总览图
python -m layout_restore.cli status
python -m layout_restore.cli report  --out metrics.md --packs out
python -m layout_restore.cli overview --out overview.png --packs out
```

---

## 3. 用自己的图

```bash
python -m layout_restore.cli build --src /path/to/your.jpg --key my_layout
```

产物在 `out/my_layout/`。把 `out/my_layout/deliver/my_layout_源件包/` 拷走，
用浏览器打开 `index.html` 就能改文字。

### 裁掉不需要的边

参考图带边框 / 水印时：

```bash
python -m layout_restore.cli build --src your.jpg --key my_layout --crop 0,0,0,0
#                                                  ↑ t,b,l,r
```

## 4. 常用调整

| 想干什么 | 改哪 |
|---|---|
| 换字体 | `config.yaml` → `build.cjk_font` / `build.latin_font` |
| 提高 OCR 召回 | `config.yaml` → `build.min_conf` 调小 |
| 像素层降级更激进 | `config.yaml` → `build.px_threshold` 调小 |
| 换取色模式 | `config.yaml` → `build.ink_mode`（`majority` / `ring`） |
| 改输出目录 | `config.yaml` → `paths.*` |

## 5. 常见问题

### Q：重建出来差异率一直下不去？

按这个顺序查：

1. **非文字区差异率是不是 0.00%？** 不为 0 → 分层错了，先修分层，别调寻优。
2. **是不是字体问题？** 把主视觉换成原图裁切块，看残差是不是掉下来。
   掉了 → 是字形替代的天花板，不是工程缺陷。
3. **是不是某几行字特别差？** 看 `deliver/<KEY>_差异热力图_活字版.png`，
   集中在某处 → 那一处有结构没拆对。

### Q：某行文字变成黑色粗体 / 出现白色鬼影？

**跨底色**。这行字横跨了两块底色，取色把「另一种底色」当成了字色。
读 [02_铁律.md](02_铁律.md) 第 7 条 —— 引擎已经处理了，
如果还出现，检查那张图是不是底色边界特别复杂。

### Q：`build` 卡住不动？

大概率是**死锁**：如果子进程输出走了 `PIPE` 而父进程最后才读，
Windows 管道缓冲（64KB）满了就会永久卡住。
本项目已经改成子进程输出直接写日志文件；如果你自己加了并行，注意这条。

### Q：能直接拿别人的电商图当参考吗？

技术上能，**但素材版权是你的责任**。本仓库的示例图全部程序生成，
就是为了不给使用者埋这个坑。

## 6. 命令速查

| 命令 | 作用 |
|---|---|
| `build` | 完整链：探针→spec→矢量层→渲染寻优→像素层→验收 |
| `probe` | 只跑探针，看拆解对不对 |
| `autospec` | 探针 → spec 草稿 |
| `vectorize` | 加矢量结构层 |
| `verify` | 从交付源件包重渲并对账 |
| `overview` | 拼总览对比图 |
| `report` | 生成指标表 Markdown |
| `status` | 打印状态板 |
