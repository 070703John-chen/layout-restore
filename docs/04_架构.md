# 04 · 架构

---

## 1. 分层铁律

> **代码写「怎么判」· 配置写「判什么·在哪」· 状态板写「到哪了」。**

| 层 | 文件 | 写什么 | 什么时候改 |
|---|---|---|---|
| **配置** | `config.yaml` | 阈值 / 路径 / 字体 / 取色模式 | **改数据** |
| **入口** | `layout_restore/cli.py` | 怎么判、怎么串、怎么并行 | **改算法** |
| **状态** | `out/*/_report.json` + `status` | 到哪了 / 差多少 | 自动生成 |

**配置是加法不是替换**：`config.py` 里有 `DEFAULTS`，
没有配置文件时用默认值 —— 子脚本永远能单独跑。

```
                  ┌──────────────┐

                  └──────┬───────┘

                  ┌──────────────┐

   │                                │──▶ deliver/（成品 + 对比图 + 热力图 + 源件包）

   └────────────────────────────────┘
```

## 3. 模块职责

| 模块 | 职责 | 关键入口 |
|---|---|---|
| `cli.py` | 唯一命令行入口，串起整条链 | `main()` |
| `config.py` | 配置读取与默认值 | `load()` / `get()` |
| `probe_layers.py` | 分层探针：OCR + 色块 + 美术层 + **取色判据** | `probe()` |
| `autospec.py` | 探针 → spec 草稿 + sweep 候选 | `main()` |
| `vectorize.py` | 矢量结构层检测（rects / lines） | `detect_rects()` / `detect_lines()` |
| `rebuild.py` | 渲染 + 寻优 + 双版本 + 交付 | `run()` |
| `pixel_fallback.py` | 像素层降级器 | `main()` |
| `verify.py` | 从交付源件包重渲对账 | `main()` |
| `overview.py` | 总览对比图 | `main()` |
| `report.py` | 指标表 Markdown | `main()` |
| `cc_color.py` `bbox_fg.py` `sample_ink.py` `zoom_regions.py` `combine_grid.py` | 量元素/看局部的辅助工具 | 各 `main()` |

## 4. 取色判据在哪儿（最常改的地方）

全部集中在 `probe_layers.py`：

```python
ink_color(img_bgr, box, mode="majority")
├─ col_bg_map(crop, outer_strip)   # 逐列局部底色
├─ bg_split(colbg)                 # 连续切分的硬边界检测
├─ ink_core_color(crop, bg_hex)    # 老路：离全局底色最远
├─ ink_stroke_color(crop, bg_hex)  # 厚度路：只留细连通块
└─ fill_vs_stroke(crop, bg_hex)    # 字腔 / 描边环分离
```

**改这里之前先读 [02_铁律.md](02_铁律.md) 第 7~10 条。**

## 5. 扩展点

| 想做的事 | 改哪儿 |
|---|---|
| 加一个版式族的判据 | `probe_layers.py` 的取色/检测函数 |
| 加一类 sweep（属性寻优） | `autospec.py` 生成 sweep 的那段 + `rebuild.py` 的 `_set_attr` |
| 换一个输出格式（不是 HTML） | `rebuild.py` 的 `build_html()` |
| 加一个 CLI 子命令 | `cli.py` 加 `cmd_xxx` + `sub.add_parser` |
| 换字体 | `rebuild.py` 的 `FONTS` 表 + `assets/` |
| 批量并发 | `cli.py` 的 `run_module()`（**输出写文件，别走 PIPE**） |

## 6. 目录产物

```
out/<KEY>/
├── index.html            活字版（唯一编辑入口）
├── index_px.html        像素层版
├── _spec.json           标定后的配方（机器可读）
├── _report.json         验收指标
├── assets/              plate.png + 字体 + 像素层素材
└── deliver/
    ├── <KEY>_像素级还原/   1x/2x 成品 + 对比图 + 差异热力图
    └── <KEY>_源件包/      index.html + assets + 还原规格说明.md
```

每个 run **自包含** —— 整个 `out/<KEY>/` 可以直接拷走给别人跑。
